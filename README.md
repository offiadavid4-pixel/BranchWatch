# BreachWatch
A responsive cybersecurity awareness dashboard built with HTML, CSS and vanilla JavaScript.

## Features
- Cybersecurity overview dashboard
- Fictional breach incident explorer
- Educational URL safety checker
- Interactive security habits checklist
- Cybersecurity knowledge quiz
- Responsive desktop and mobile layout

## Open in PyCharm
1. Download and extract `BreachWatch.zip`.
2. Open PyCharm and choose **File → Open**.
3. Select the extracted `BreachWatch` folder.
4. Open `index.html`, right-click in the editor, and choose **Open in Browser**.

No Python packages, Node.js, or database are required.

## Safety note
All breach records are fictional. The URL checker performs basic checks in your browser; it does not query threat-intelligence services, scan websites, or guarantee a URL is safe.
